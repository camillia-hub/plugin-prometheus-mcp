# Prometheus MCP

Queries Prometheus. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/prometheus-mcp

Installs from the Camillia hub as `prometheus-mcp-5a10a4`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
